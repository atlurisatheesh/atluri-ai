1. BACKEND WebSocket Protocol (ws://localhost:9010/ws/voice):
   
   Connection URL query params:
     ?room_id=<string>
     &participant=interviewer|candidate
     &assist_intensity=1|2|3
     &role=<scenario_name>
     &company=<string>
     &position=<string>
     &objective=<string>
     &image_analysis_context=<string>
     &priority_questions=<string>
     &interview_procedures=<string>
     &model_id=<string>

   Incoming messages (client → backend):
     Binary PCM16 frames     → Audio data (16kHz mono, 20ms chunks)
     {"type":"transcript", "text":"...", "participant":"interviewer", "is_final":true}
                              → Text transcript (fallback when no audio)
     {"type":"stop"}          → End session
     {"role":"behavioral"}    → Set interview role

   Outgoing messages (backend → client):
     {"type":"room_assigned", "room_id":"..."}
     {"type":"transcript_ack", "text":"..."}
     {"type":"interviewer_question", "data":{"text":"..."}}
     {"type":"question_intelligence", "data":{...}}
     {"type":"answer_suggestion_start", "data":{"question":"..."}}
     {"type":"answer_suggestion_chunk", "data":{"text":"...", "is_thinking":true/false}}
     {"type":"answer_suggestion_done", "data":{"suggestion":"...", "question":"..."}}
     {"type":"answer_suggestion", "data":{"answer":"...", "key_points":[...]}}
     {"type":"coach_feedback", "data":{"pacing":"...", "trap_alert":"..."}}
     {"type":"offer_probability", "data":{"probability":0.85}}

   IMPORTANT: The backend uses QA_MODE=true to bypass Deepgram (no real STT needed).
   IMPORTANT: Set ROOM_EVENT_BUS_ENABLED=false in backend/.env to avoid Redis dependency.
   IMPORTANT: ws_voice.py had a logger shadowing bug at line ~697. If WS connects then
   immediately closes with code 1006, check that module-level `logger` is used before
   the local `_SessionStructuredLogger` is assigned.
